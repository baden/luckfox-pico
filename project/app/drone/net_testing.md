# Тестування мережі

## Пінгування.

Окрім звичайного пінгування, можна додавати параметри.
Наприклад встановити розмір пакетів шоб виявити який MTU проходить.

```
ping -D -s 1202 10.0.0.101
```


На одному з вузлів, до якого тестуєте звʼязок, запустить:

```
iperf3 -s -p 5001
```

З іншого пристрою, на іншому боці тестуємого напрямку:

```
iperf3 -c 46.225.8.20 -u -b 2M -t 20 -l 1200 -p 5001
```
