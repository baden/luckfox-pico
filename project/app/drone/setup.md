# Інструкція по налаштуванню.


## Налаштування камер.

Камери налаштовуються на мережу 10.0.0.0/24.
Для передньої камери оберається адреса 10.0.0.101, маска 255.255.255.0, gateway можна не налаштовувати якшо не треба стрімінг потужностями самої камери.
Для задньої камери 10.0.0.102.
Для додаткових камер відповідно 103, 104, ...

## Мережа

Дрон працює в VPN-мережі. Тут і далі описана робота через Wireguard.
Реалізація може бути і інша.

Плата керування дрона має адресу 10.8.0.2.
Адреса оператора дрона може бути, наприклад 10.8.0.3.
Якшо треба, можна додавати додаткових операторів, чи спостерігачів, призначаюси адреси 10.8.0.4, 10.8.0.5 і т.д.


## Налаштування обладнання оператора.

Треба встановити [Wireguard](https://www.wireguard.com/install/).

Створити мережу. В налаштуваннях вже частвово будуть строчки.
Поміняти адресу `Address = ` на значення в мережі 10.8.0.x/24.
Створити `[Peer]` як в прикладі далі, тільки вказати реальну адресу
сервера `Endpoint` та публічний ключ сервера `PublicKey =`.
Також вказати у AllowedIPs всі камери. Чи можна вказати 10.0.0.0/24 якшо перелік камер заздалегідь невідомий.


```
[Interface]
PrivateKey = не чіпати, буде заповнене
Address = 10.8.0.3/24
MTU = 1280

[Peer]
PublicKey = _публічний_ключ_сервера_
AllowedIPs = 10.8.0.0/24, 192.168.1.108/32, 10.0.0.101/32, 10.0.0.102/32
Endpoint = _IP_сервера_:51820
```

Треба взяти значення із строчки "Публічний ключ" і передати його разом з IP админістратору сервера, для створення відповідного піра на сервері.


## ПО для керування.

Після налаштування і активації VPN, можна користуватись будь яким ПО для доступа до камер.

Основний потік у камери доступний через RTSP:

```
rtsp://admin:password@10.0.0.101:554/cam/realmonitor?channel=1&subtype=0
```

Додатковий потік:

```
rtsp://admin:password@10.0.0.101:554/cam/realmonitor?channel=1&subtype=1
```

На платі керування встановлено ПО для роботи з камерою через RTC.

Налаштування камер по посиланню:

```
http://10.8.0.2:1984/config.html
```

Приклад посилання для камери:

```
http://10.8.0.2:1984/stream.html?src=rear
```



При тестах довелось включати дещо у флагах Google Chrome.
